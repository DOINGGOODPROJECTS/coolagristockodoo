Cool Agristock

Connect Odoo 19 Inventory with Cool Agristock, an open-source warehouse management system for agribusinesses.

Who it's for

Agricultural cooperatives, agribusinesses, processors, and input distributors — built for businesses in Africa and other emerging markets, though nothing restricts it to any particular region — that already use Odoo 19 and run a compatible external warehouse management system (WMS) they need to keep in sync with Odoo Inventory, instead of re-entering receipts and dispatches by hand in both places.

What it does

Cool Agristock is a free, open-source Odoo 19 application that enables businesses to connect compatible external Warehouse Management Systems (WMS) to Odoo Inventory through a secure REST API. It exposes that API so the WMS can read and write product, warehouse, and supplier data; configure unit-of-measure mappings; create and resolve lots and serial numbers; stage initial inventory counts for human review; and create and validate incoming receipts and outgoing dispatches — including lot/serial-tracked products — without a human re-keying anything into Odoo. Cool Agristock remains a standalone application; this module is the bridge between the two systems.

Initial stock counts from your WMS are staged in Odoo for review, not applied automatically. An Inventory Manager compares the WMS's count against Odoo's own records and decides what to do — applying an approved count to actual stock is a separate, manual action in Odoo's native Inventory Adjustment screen. This keeps a human in the loop for every change to your real inventory levels.

Businesses generate and manage their own API keys directly inside the application — creating, naming, revoking, and replacing them without needing Cool Agristock's developers or an external administrator. Each key can be given an expiration date or left to remain valid until manually revoked. Using the generated credentials and the documented REST API, businesses with a compatible WMS can configure their own integration independently; a WMS that isn't natively compatible with this API may require custom integration services (see below).

Optional professional services (paid)

Cool Agristock itself is, and remains, free and open-source. For businesses that want help going further, the team behind Cool Agristock separately offers optional paid services:

Résumé — Français

Fonctionnalités principales

  • API REST pour produits, entrepôts, fournisseurs et stock, référencés par vos propres identifiants externes
  • Correspondance d'unités de mesure, gestion des lots et numéros de série, réceptions et expéditions (y compris produits tracés)
  • Import initial du stock mis en attente pour validation humaine — jamais appliqué automatiquement
  • Gestion autonome des clés API (création, expiration, révocation) sans administrateur système

Sécurité

  • Clés API générées et gérées par l'entreprise elle-même, protégées par jeton Bearer
  • Accès réservé aux groupes Cool Agristock Administrator / Cool Agristock API User
  • Isolation multi-société : une société ne peut jamais voir ni révoquer les clés d'une autre
  • HTTPS recommandé en dehors d'un usage local

Limites connues

  • Le WMS externe doit prendre en charge l'API documentée (ou un adaptateur)
  • Aucune synchronisation automatique : chaque requête est initiée par le WMS
  • Traitement partiel des réceptions/expéditions non pris en charge (quantités exactes requises)
  • Pagination non disponible sur les listes

Prérequis

  • Odoo 19
  • Modules OCA : connector, component, component_event, queue_job

Données et confidentialité

Le module n'envoie aucune donnée de lui-même ; il répond uniquement aux requêtes du système externe connecté via une clé API.

Summary — English

Key features

  • REST API for products, warehouses, suppliers and inventory, addressed by your own external IDs
  • UOM mapping, lot/serial handling, receipts and dispatches, including tracked products
  • Initial inventory import staged for human review — never applied automatically
  • Self-service API key management, no System Administrator required

Security

  • API keys generated and managed by the business itself, protected by Bearer token
  • Access restricted to the Cool Agristock Administrator / Cool Agristock API User groups
  • Multi-company isolation: one company can never view or revoke another's keys
  • HTTPS recommended outside local development

Known limitations

  • The external WMS must support the documented API, or use an adapter
  • No automatic sync: every request is initiated by the WMS
  • Partial receipt/dispatch processing not supported (exact quantities required)
  • Pagination not available on list endpoints

Requirements

  • Odoo 19
  • OCA modules: connector, component, component_event, queue_job

Data & privacy

The module sends no data anywhere on its own; it only responds to requests from the external system an authorized user connects via an API key.
