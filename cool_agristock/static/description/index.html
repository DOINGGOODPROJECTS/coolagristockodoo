Cool Agristock

Connect Odoo 19 Inventory with Cool Agristock, an open-source warehouse management system for agribusinesses.

Who it's for

Agricultural cooperatives, agribusinesses, processors, and input distributors — originally built for businesses operating in Côte d'Ivoire and other African markets, though nothing restricts it to any particular region — that already use Odoo 19 and run a compatible external warehouse management system (WMS) they need to keep in sync with Odoo Inventory, instead of re-entering receipts and dispatches by hand in both places.

What it does

Cool Agristock is a free, open-source Odoo 19 application that enables businesses to connect compatible external Warehouse Management Systems (WMS) to Odoo Inventory through a secure REST API. It exposes that API so the WMS can read and write product, warehouse, and supplier data; configure unit-of-measure mappings; create and resolve lots and serial numbers; stage initial inventory counts for human review; and create and validate incoming receipts and outgoing dispatches — including lot/serial-tracked products — without a human re-keying anything into Odoo. Cool Agristock remains a standalone application; this module is the bridge between the two systems.

Initial stock counts from your WMS are staged in Odoo for review, not applied automatically. An Inventory Manager compares the WMS's count against Odoo's own records and decides what to do — applying an approved count to actual stock is a separate, manual action in Odoo's native Inventory Adjustment screen. This keeps a human in the loop for every change to your real inventory levels.

Businesses generate and manage their own API keys directly inside the application — creating, naming, revoking, and replacing them without needing Cool Agristock's developers or an external administrator. Each key can be given an expiration date or left to remain valid until manually revoked. Using the generated credentials and the documented REST API, businesses with a compatible WMS can configure their own integration independently; a WMS that isn't natively compatible with this API may require custom integration services (see below).

Key features

  • REST API for products, warehouses, suppliers, and on-hand inventory, addressed by your own external IDs
  • Unit-of-measure mapping for units Odoo doesn't ship with by default
  • Lot and serial number creation and resolution for traceable products
  • Staged initial inventory import, reviewed and applied manually by an Inventory Manager — never applied automatically
  • Create and validate stock receipts (incoming deliveries), including lot/serial-tracked products
  • Create and validate stock dispatches (outgoing deliveries), including lot/serial-tracked products
  • Look up the status of a receipt or dispatch by your own external reference
  • Self-service API key management: generate, name, set an expiration or make permanent, view status, revoke, and replace keys, without needing Odoo System Administrator access
  • Dedicated role-based access group for external integrations, with multi-company isolation
  • Concurrency-safe duplicate protection on receipt/dispatch creation

Security and Permissions

  • Self-service API key generation: an authorized business user creates, names, and manages API keys directly inside Cool Agristock — no developer or external administrator involvement is needed
  • Authorized user access: only users in the Cool Agristock Administrator group can generate, revoke, or replace API keys; only users in the Cool Agristock API User group (or a group that implies it) can call the REST API itself
  • API key expiration and revocation: a key can be given an expiration date or left to remain valid until manually revoked; revocation takes effect immediately, enforced by Odoo's own API key infrastructure
  • Bearer-token authentication: every protected endpoint requires a valid Odoo API key sent as an Authorization: Bearer header
  • Multi-company security controls: API key records are isolated per company by record rules, so one company's administrators can never view or revoke another company's keys
  • Secure communication recommended: deploy behind HTTPS in any environment beyond local development, since Bearer tokens sent over plain HTTP are visible on the network path

Known Limitations

  • The external WMS must support the documented REST API, or use an adapter, to integrate — not every warehouse system is automatically compatible
  • No automatic or scheduled synchronization: every request is initiated by the external WMS
  • Initial inventory imports are staged for human review — applying a reviewed count to actual Odoo stock still requires one manual step in Odoo's own Inventory Adjustment screen, by design
  • Partial receipt and dispatch processing is not currently supported; quantities must match exactly
  • Warehouse-specific access controls are not currently implemented; access is scoped by company only
  • Pagination is not currently supported on list endpoints

Requirements

  • Odoo 19
  • OCA connector, component, component_event, and queue_job modules

Data & integration

This module does not send any data anywhere on its own. It only responds to requests from whichever external system an authorized business user explicitly connects by generating an API key, and only for the data categories documented above (products, warehouses, suppliers, UOM mappings, lots and serial numbers, inventory, receipts, and dispatches). No data is shared with Cool Agristock's authors or any third party.
