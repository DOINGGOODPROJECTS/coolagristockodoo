Cool Agristock

Connectez votre WMS agricole à Odoo Inventory

Cool Agristock est une application gratuite et open source pour Odoo 19 qui permet de connecter des systèmes externes de gestion d'entrepôt (WMS) compatibles à Odoo Inventory via une API REST sécurisée. Conçue pour les entreprises agricoles, elle simplifie les opérations de gestion des stocks, réduit la saisie manuelle et améliore la cohérence des données entre les systèmes.

Connect Your Agricultural WMS to Odoo Inventory

Cool Agristock is a free, open-source Odoo 19 application that connects compatible external Warehouse Management Systems (WMS) to Odoo Inventory through a secure REST API. Designed for agribusinesses, it simplifies inventory operations, reduces manual data entry, and improves warehouse data consistency.

Fonctionnalités principales

  • Échange de données sur les produits, les entrepôts et les fournisseurs
  • Correspondance des unités de mesure
  • Traçabilité par lots et numéros de série
  • Traitement automatisé des réceptions et des expéditions de marchandises
  • Inventaires initiaux soumis à la vérification d'un responsable — les ajustements réels des stocks restent manuels, via la fonctionnalité native d'ajustement des stocks d'Odoo

Key Features

  • Product, warehouse, and supplier data exchange
  • Unit-of-measure mapping
  • Lot and serial number tracking
  • Automated processing of incoming stock receipts and outgoing dispatches
  • Initial inventory counts from external systems staged for manager review — actual stock adjustments are always applied manually, through Odoo's native Inventory Adjustment functionality

API REST sécurisée et gestion des clés API

  • API REST sécurisée et documentée pour l'échange des données d'entrepôt et de stock
  • Génération, nommage, révocation et remplacement des clés API directement depuis l'application
  • Paramètres d'expiration flexibles pour une gestion sécurisée et autonome des accès

Secure REST API & API Key Management

  • Secure, documented REST API for seamless warehouse and inventory data exchange
  • Generate, name, revoke, and replace API keys directly within the application
  • Flexible expiration settings for secure and independent access management

The API Management screen, where an authorized business user generates, views, and revokes their own API keys. The key's secret value is shown only once, at the moment it is generated, and is never displayed again afterward.

The REST API's health check endpoint, confirmed live and responding.

Prérequis techniques

  • Un serveur Odoo 19 existant avec l'application Inventaire installée
  • Un accès administrateur pour la configuration
  • Un système externe de gestion d'entrepôt (WMS) compatible, capable de communiquer via l'API REST
  • Modules OCA : connector, component, component_event, queue_job

System Requirements

  • An existing Odoo 19 server with the Inventory application installed
  • Administrator access for configuration
  • A compatible external WMS capable of communicating through the REST API
  • OCA modules: connector, component, component_event, queue_job
